# Ambu360 — Site institucional

Site institucional independente do aplicativo Ambu360, preparado para deploy no Coolify.

- Fonte: repositório `parrillasbrasil/ambu360-site`, branch `main`
- Build Pack: Dockerfile
- Porta interna: `80`
- Domínio: `https://ambu360.com.br`
- Auto Deploy: ativar no Coolify para pushes na branch `main`

O conteúdo apresenta a visão de lançamento da plataforma, inclusive módulos planejados que devem ser validados antes da divulgação pública. Formulário de contato utiliza WhatsApp da Modtrax como canal provisório e deve ser revisado antes do lançamento.

**IMPORTANTE:** Este site é independente do sistema SaaS/portal dos clientes. Não coloque credenciais do Firebase nem da aplicação neste repositório.
